## ADDED Requirements

### Requirement: Ability score generation

A new character's six ability scores (STR, INT, WIS, DEX, CON, CHA) SHALL be
generated by rolling `3d6` in order, with one OSE-sanctioned swap of a single pair
offered at creation. Scores SHALL NOT default to a flat value.

#### Scenario: Scores are rolled, not flat
- **WHEN** a character is created through the creation flow
- **THEN** each ability score is the result of a `3d6` roll (range 3–18)
- **AND** the player may swap exactly one pair of scores before finalizing

### Requirement: Class and race selection gated by prime requisites

The flow SHALL let the player choose one class — Cleric, Fighter, Magic-User,
Thief — or one race-class — Dwarf, Elf, Halfling (no multiclass). A class SHALL be
selectable only if the rolled scores meet its OSE prime-requisite minimum; if no
class qualifies, the flow SHALL allow a re-roll.

#### Scenario: Only qualifying classes are offered
- **WHEN** the player reaches class selection with a given set of scores
- **THEN** only classes whose prime-requisite minimum is met are selectable
- **AND** the chosen class is stored on the character (`db.char_class`)

#### Scenario: No qualifying class permits a re-roll
- **WHEN** the rolled scores qualify for no class
- **THEN** the flow offers to re-roll the ability scores

### Requirement: Derived starting statistics

On finalizing creation, the character's level-1 statistics SHALL be derived from
the chosen class and the OSE class/level tables: hit points (`roll class HD + CON
mod`, minimum 1), ascending armor class (`10 + DEX_mod`, before equipment), attack
bonus, and saving throws.

#### Scenario: Level-1 stats reflect the class
- **WHEN** creation finalizes for a chosen class
- **THEN** the character has level 1, HP rolled from that class's hit die plus CON modifier (min 1)
- **AND** attack bonus and saves match the class+level table for level 1

### Requirement: Starting gold and hardcore opt-in

The flow SHALL grant `3d6 × 10` gp starting gold and SHALL offer an irrevocable
hardcore opt-in recorded on the character at creation.

#### Scenario: Starting gold and hardcore flag
- **WHEN** creation finalizes
- **THEN** the character has starting gold in `[30, 180]` gp
- **AND** if the player opted into hardcore, the character's hardcore flag is set (and can never be cleared)

### Requirement: Spawn into the world

A character finished through the creation flow SHALL spawn at the recall point
(the Inner Bailey), consistent with the existing new-character placement.

#### Scenario: Created character is in the Keep
- **WHEN** the player enters the world after creation
- **THEN** the character's location is the Inner Bailey recall room
